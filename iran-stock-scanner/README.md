# شکارچی فرصت بورس ایران — نسخه اولیه مستقل

این برنامه در مسیر `iran-stock-scanner/` قرار دارد و از ریشه پروژه WAL جداست؛ برای اجرای آن سرویس میزبانی جداگانه بسازید و Root Directory را روی `iran-stock-scanner` قرار دهید.

## اجرا
- Build: Dockerfile
- Health check: `/health`
- Dashboard: `/`
- Status: `/api/status`
- Market data: `/api/market`
- Negative candidates: `/api/scan`

## داده و محدودیت‌ها
- تلاش می‌کند داده دیده‌بان را از مسیر webgw.tse.ir دریافت کند و یک مسیر جایگزین TSETMC دارد.
- این endpointها غیررسمی/بدون SLA هستند و ممکن است تغییر کنند یا دسترسی خارجی را مسدود کنند. برای بعضی مسیرهای TSETMC، IP ایران لازم است؛ قبل از ادعای LIVE، مسیر باید از سرور مستقرشده آزمایش شود.
- برنامه اگر پاسخ قابل تشخیص نگیرد، OFFLINE نشان می‌دهد؛ داده ساختگی نمی‌سازد.
- فهرست منفی‌ها صرفاً فیلتر اولیه است، نه سیگنال خرید.
- ماژول بنیادی و تاریخچه تکنیکال هنوز به منابع معتبر و آزمون‌شده وصل نشده‌اند؛ بنابراین سیگنال خرید تا تکمیل و اعتبارسنجی این داده‌ها عمداً مسدود است.
- هیچ تضمینی برای خطای صفر یا تأخیر صفر وجود ندارد. برنامه سن داده و خطا را نمایش می‌دهد و داده قدیمی را به‌عنوان LIVE معرفی نمی‌کند.

## پیش‌نیاز نسخه تولیدی
1. تست دسترسی TSETMC از IP میزبان، در ساعات معامله و خارج از ساعات معامله.
2. پیاده‌سازی/اعتبارسنجی parser برای schema واقعی market-watch.
3. دریافت تاریخچه تعدیل‌شده و جریان حقیقی/حقوقی به‌ازای هر نماد.
4. دریافت گزارش‌های مالی و اطلاعیه‌های کدال، مدیریت دوره مالی و تعدیلات سرمایه.
5. آزمون‌های واحد، آزمون منبع و backtest بدون look-ahead bias.
6. هشدار برای منبع کهنه/قطع‌شده و پایش uptime.

## استقرار روی Render
1. New + Web Service را انتخاب کنید.
2. همین repository را وصل کنید.
3. Root Directory: `iran-stock-scanner`
4. Runtime: Docker
5. Health Check Path: `/health`
6. پس از Deploy، ابتدا `/health` و سپس `/api/status` را باز کنید. تا وقتی status برابر LIVE نشده، داده را زنده فرض نکنید.

این نرم‌افزار ابزار غربالگری اطلاعاتی است و سفارش معامله ثبت نمی‌کند.
